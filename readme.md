# IoT Data Intelligence Platform

A full stack platform for intelligent analysis of IoT data.

The **IoT Data Intelligence Platform** is a portfolio project designed to demonstrate how IoT data can be transformed into useful insights through a complete web application.

The platform will allow users to upload IoT datasets, visualize sensor metrics through dashboards, and interact with an AI assistant to analyze patterns, alerts, and anomalies.

## Project Purpose

IoT systems generate large volumes of data from sensors, devices, gateways, and applications. However, raw data alone does not support decision-making.

This project aims to show how a modern software architecture can transform raw IoT records into structured information, visual indicators, and AI-assisted insights.

## Planned Features

- User authentication
- IoT dataset upload
- CSV data validation
- PostgreSQL database integration
- Analytical dashboard
- Sensor status monitoring
- Alert analysis
- AI assistant for IoT data interpretation
- Docker-based deployment
- Nginx reverse proxy configuration
- Production deployment on a VPS

## Tech Stack

- **Backend:** FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Migrations:** Alembic
- **Frontend:** React
- **Data Processing:** Pandas
- **AI:** OpenAI API
- **Infrastructure:** Docker, Docker Compose and Nginx
